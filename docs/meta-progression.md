# Meta-progression: Unlockables and Boosts

Decided 2026-11-20 after playtest 1. Milestones are gone; Air Miles buy everything.

## Always available
Runways (all lengths), Taxiways, Contact Stands, Holding Bays, Land Plots, every Runway Surface (Grass, Asphalt, Lit, ILS), Tower Modules levels 1–3, Ground Stop.

## Unlockables (bought once) *(prices are first guesses)*
| Unlockable | Air Miles | Effect |
|---|---|---|
| Remote Stands | 300 | Place Remote Stands |
| Admin Office | 300 | Building; enables Manual Divert |
| Grass strip | 300 | Cheap Short Grass Runways (12k) |
| Terminal wing | 400 | Extend the Terminal |
| Cargo Hub wing | 400 | Extend the Cargo Hub |

| Cargo apron lighting | 500 | Cargo Turnarounds −20% after dusk |

| Tower Modules 4–5 | 1,200 | Tower Module levels 4 and 5 |
| Second Terminal | 1,500 | Place a free-standing Terminal with its own Contact Stands |

## Boosts (levels, 500 Air Miles × next level)
Higher fees (+5%/level), Lower Upkeep (−5%), Longer Fuel Reserve (+5 min), Shorter cooldowns (−10%), Faster Turnaround (−5%), Cheaper Taxiways (−10%), Cheaper Land (−10%), Lower Crash Fines (−10%), Faster fire crews (−10% blockage, needs Fire & Rescue Station), Starting Money (+15k), Starting Holding Bay (1 level: a third, Medium Holding Bay), Larger starting land (1 level), Better starting Radar (2 levels).

A Boost for a locked building stays locked (🔒 "Needs: …").

## Flow
Main Menu (Continue · New Run · Unlockables & Boosts · Options · About) → Run → Day report each Day → Score Screen at the end (last Day + Run totals, won/lost, Air Miles) → Finish Run → Main Menu.

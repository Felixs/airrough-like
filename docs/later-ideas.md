# Later ideas (parked)

Ideas deliberately left out of v1, to revisit later.

- **Airline Contracts**: in Plan Mode, accept optional contracts (e.g. "daily A320 service") that add traffic and income on top of the Schedule. Candidate for an NG+ / post-first-win difficulty mode where contracts raise both difficulty and rewards.
- **Delay penalties**: reduce Arrival/Departure Fees when flights are late.
- **Staff & hiring**: ground crew, controllers etc. as a separate resource on top of Upkeep.
- **Building throughput**: Terminals/Cargo Hubs with per-hour passenger/cargo capacity; overload slows Turnarounds.
- **Simulated passengers & cargo**: individual people/freight flowing through security, baggage, warehouses.
- **VIP Twist Family**: private jet → charter → state visit; losing the VIP flight costs a big extra fine.
- **Runway shutdown Emergency Action**: close a specific Runway on demand during a Live Day (use case still unclear).
- ~~Close the Airport action~~: rejected. It would allow skipping Boss Days; replaced by the automatic Airport Closed state.
- **Hard mode (Regional Field)**: Short Grass Runway, 2 Small Stands. Needs its own Schedule/swap rule to be tough but beatable (ideas: always swap to Small with ~70% traffic; fade the swap out by Week 3–4; swap to the next size down). Bonus Air Miles.
- **Custom mode**: ATC Tower only, Player-set starting Money, Air Miles scaled down with more Money.
- **Routing Rules**: Player-set constraints for the ATC Tower (e.g. "Runway 2 cargo only"), unlocked later in a Run or via meta-progression.

## Custom starting airport builder (Main Menu) — requested 2026-11-20
A builder step in the Main Menu where the Player designs their own starting airport: same Land Plots as the default Starting Airport and the same Money it would cost to build it, laid out however they like. At the start of a New Run the Player chooses the default Starting Airport or one of their own builds.

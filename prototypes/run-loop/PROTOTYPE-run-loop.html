THROWAWAY PROTOTYPE

Airport Auto Battler · Does the Run loop feel right?

Question: with the new rules (lose by missing a Daily Quota once; Crashes cost Crash Fines; Airport Closed diverts instead of crashing; Saturday Rush Day; stronger traffic; ATC upgrades shorten Runway Separation), does a 4-Week Run force real building choices, and does the Run Calendar let you prepare for each Boss Day?

Quota = 75% of the Day's Demand in Movements (landings + takeoffs), 90% on Boss Days. Each Day auto-plays the Live Day simulation. On a Fuel Alert it uses Manual Divert if built, else Priority Landing; on an Emergency Alert it always intervenes. "Autopilot" is a prototype helper that builds with a simple rule set so you can fast-forward; it is not a game feature. The simulation steps every 15 seconds. Runway Separation goes from 4 min (landing) / 3 min (takeoff) down to 2 / 1.5 min as Radar and Controller Training rise. Large aircraft only appear from Thursday of Week 2. Each extra copy of the same Stand, Holding Bay or Runway costs 25% more than the last. Each Size Class only sends as many flights as its fitting Stands can absorb (Small 10, Medium 8, Large 6 per Stand per Day). Crash Fines: Small 5k / Medium 10k / Large 20k, +50% per earlier Crash that Week, capped at ×3. A plane at minimum fuel diverts when no Runway that fits it is open. Prices are first guesses. Same seed = same Run.
